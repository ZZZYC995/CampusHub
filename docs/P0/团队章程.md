## AI工具链选型及理由
AI编程助手：Claude Code
候选1：Claude Code
优势：长文理解力强，代码逻辑完整、免费，适合校园项目
候选2：通义灵码
劣势：复杂逻辑生成能力弱，易出错
AI对话工具：ChatGPT
候选1：ChatGPT
优势：响应快，使用简单，适合快速生成初稿
候选2：Claude
劣势：响应速度慢
AI代码审查工具：AI Code Review
候选1：CodeRabbit
劣势：配置稍复杂
候选2：AI Code Review
优势：开箱即用，无需额外安装
AI测试工具：TestGPT
候选 1：Claude Code测试生成
劣势：需要手动复制粘贴
候选 2：TestGPT
优势：专用测试生成，用例规范
