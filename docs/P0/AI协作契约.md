# AI 协作契约
团队名称：未命名小队

日期：2026年4月14日

## 一、AI 使用原则
1. AI 为辅助工具，团队成员承担最终责任。
2. 所有 AI 输出必须经人工审查后方可使用。

## 二、AI 使用范围
允许使用：代码生成、文档初稿、注释、测试用例。  
禁止直接使用 AI 输出：业务逻辑、核心算法、数据库设计。  
完全禁止使用：反思日志、需求访谈和调研、成果报告提交。

## 三、过程记录要求
1. 保存 AI 交互 Prompt 日志。
2. Git 提交标注 [AI-assisted] 或 [Human-written]。
3. 按时完成各阶段 AI 协作反思日志。

## 四、代码合入规则
1. AI 生成代码必须经过 Code Review。
2. 每人每个编码阶段至少手写 2 个核心函数。
3. 禁止未经审查直接合并代码。

## 五、违约处理
1. 首次：警告并重新审查。
2. 二次：取消阶段贡献。
3. 三次：上报课程负责老师。
